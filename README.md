# Vavilon Calc
> "WHAT YOU BUILDED, WHAT YOU DESTROYED?" - Aria (Russian Rock group)

###  10 Langs!
We use Rust, C, C++, Ada, Vala, Nim, Zig, Go, D, and Lua. Every binary
operation is split into eight mathematically equivalent pieces. Rust, Go,
Zig, D, Nim, C++, and Ada each calculate one piece; Lua calculates the eighth
piece and aggregates all eight before Vala displays the answer.

# how to build
Install dmd, go, zig, gcc, gnat, nim, rustc, lua, GTK 3, and run `make`.
