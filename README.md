# Vavilon Calc
> "WHAT YOU BUILDED, WHAT YOU DESTROYED?" - Aria (Russian Rock group)

###  11 Langs!
We use Rust, C, C++, Ada, Vala, Nim, Zig, Go, D, Perl, and Lua. Every binary
operation is split into nine mathematically equivalent pieces. Rust, Go,
Zig, D, Nim, C++, Ada, and Perl each calculate one piece and Lua calculates the
ninth piece and aggregates all nine before Vala displays the answer.

# how to build
Install dmd, go, zig, gcc, gnat, nim, rustc, lua, perl, GTK 3, and run `make`.
