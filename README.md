# Vavilon Calc
> "WHAT YOU BUILDED, WHAT YOU DESTROYED?" - Aria (Russian Rock group)

###  8 Langs!
We use Rust, C, Vala, Nim, Zig, Go, D, and Lua. Every binary operation is
split into six mathematically equivalent pieces. Rust, Go, Zig, D, and Nim
each calculate one piece; Lua calculates the sixth piece and aggregates all
six before Vala displays the answer.

# how to build
Install dmd, go, zig, gcc, nim, rustc, lua, GTK 3, and run `make`.
