> "WHAT YOU BUILDED, WHAT DESTROYED?" - Aria (Russian Rock group) "Вавилон" 

###  12 Langs!
We use Rust, C, C++, Ada, Vala, Nim, Zig, Go, D, Perl, NotAByte and Lua. Every binary
operation is split into nine mathematically equivalent pieces. Rust, Go,
Zig, D, Nim, C++, Ada, NotAByte, and Perl each calculate one piece and Lua calculates the
ninth piece and aggregates all nine before Vala displays the answer.

# how to build

make sure you update submodules before building

```bash
git submodule update --init
```
Install dmd, go, zig, gcc, gnat, nim, rustc, lua, perl, GTK 3, valac and run `make`.
